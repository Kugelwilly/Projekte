# Google Translator CLI (Python)

Ein einfaches Kommandozeilen-Tool zur Nutzung der **Google Cloud Translation API**, entwickelt mit **Python** als Lernprojekt im Bereich API-Integration und Konsolenanwendungen.

---

## Projektbeschreibung

Dieses Projekt ist ein interaktiver CLI-Übersetzer, der Texte mithilfe der Google Cloud Translation API in verschiedene Sprachen übersetzt.

Es wurde entwickelt, um den Umgang mit APIs, HTTP-Requests und JSON-Datenstrukturen in Python zu üben.

Die Bedienung erfolgt vollständig über die Konsole, ohne grafische Oberfläche.

---

## Features

- Textübersetzung über Google Cloud Translation API
- Unterstützung mehrerer Sprachen (z. B. de, en, fr)
- Interaktive CLI-Eingabe
- API-Key wird zur Laufzeit eingegeben
- Abbruch durch Eingabe von `X`
- Fehlerbehandlung bei API- oder Netzwerkproblemen
- JSON-Antwortverarbeitung

---

## 🛠️ Technologien

- Python 3
- `requests` Library
- Google Cloud Translation API
- JSON Verarbeitung

---

## 🔑 Voraussetzungen

Vor der Nutzung wird ein gültiger Google API Key benötigt:

- Google Cloud Projekt erstellen
- Cloud Translation API aktivieren
- API Key generieren
