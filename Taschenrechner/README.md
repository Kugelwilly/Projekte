# Taschenrechner (Python + CustomTkinter)

Ein einfacher, moderner Taschenrechner, entwickelt mit **Python** und **CustomTkinter** als Lernprojekt im Bereich Softwareentwicklung.

---

## Projektbeschreibung

Dieses Projekt ist ein grafischer Taschenrechner mit einer modernen Benutzeroberfläche.  
Er wurde als Übungsprojekt entwickelt, um den Umgang mit Python, GUI-Entwicklung und Logikstrukturen zu verbessern.

Der Taschenrechner unterstützt grundlegende Rechenoperationen sowie eine dynamische Anzeige.

---

## Features

- Addition
- Subtraktion
- Multiplikation
- Division
- Dezimalzahlen
- Löschen (Backspace)
- Komplett-Reset (C)
- Automatische Ergebnisberechnung
- Moderne GUI mit CustomTkinter
- Dynamische Schriftgröße je nach Eingabelänge
- Fehlerbehandlung (z. B. Division durch 0)

---

## 🛠️ Technologien

- Python 3
- CustomTkinter
- Built-in `eval()` für Berechnung
